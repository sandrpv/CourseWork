# CourseWork: Cactus Cleaner

Course project from my studies at Step IT Academy. It contains the first version of **Cactus Cleaner**, a Windows utility for system cleanup and maintenance, together with the written course paper.

The finished version of the project is in [Graduate_work](https://github.com/sandrpv/Graduate_work).

## About the project

Cactus Cleaner brings several everyday maintenance tools into one application:

- deleting unnecessary files
- managing autorun programs
- cleaning up RAM
- applying Windows 10 tweaks

## Tech stack

- **Language:** C#
- **Platform:** Windows

## Repository contents

```
CourseWork/
├── CC - cactus cleaner/     # source code of the application
└── Курсовая работа.docx     # course paper (Russian)
```

## Build and run

1. Install [Visual Studio](https://visualstudio.microsoft.com/) with the **.NET desktop development** workload.
2. Clone the repository:
   ```bash
   git clone https://github.com/sandrpv/CourseWork.git
   ```
3. Open the solution inside `CC - cactus cleaner/` and build it (`Ctrl+Shift+B`).
4. Run the program. Some features may need **administrator rights**.
